## Deliberate limits / unverified areas

- Only Windows x64 runtime/build tested. Linux/macOS compilation, C ABI visibility there, mobile native builds and browser/WASM integration remain unverified.
- Current codecs: JPEG/PNG/WebP SDR, sRGB input contract. No HEIF/HEIC/AVIF/RAW decoder, ICC conversion, HDR tonemapping or generative dewarp/deblur. 16-bit PNG is normalized to 8-bit for JPEG/PDF; it is not a 16-bit archival output pipeline.
- No bot/OCR/server integration, login or web change belongs to this library delivery. External systems choose their own wrappers, I/O, persistence and OCR.
- Cooperative cancellation is tested as sticky cancel/reset. A codec or ORT call cannot be interrupted immediately; active-call timing/concurrency stress and hard process RAM quotas were not verified.
- Native classifier keeps the existing bootstrap model. This work verifies loading/execution and pixel policy behavior; broader real-camera validation and profile-managed color parity need their own datasets.

## Enhanced-color v2 quality update — 2026-10-24

This follow-up changes both the sibling web and native Enhanced kernels; they remain independent implementations with no runtime dependency between them. C ABI v1 and output resolution/JPEG96/4:4:4/PDF contracts are unchanged. Native Enhanced now measures the final frame instead of warping a 720px analysis image. The new ink-only detail stage uses three luminance rows, at most 9,000 extra bytes for width3000; unchanged RGB channel differences, no new clipping or bright paper halos, conservative noise/crisp/periodic-content protection. This is slight clarity enhancement, not deblurring.

The old native pixel executable failed the new web goldens before rebuilding. The optimized uniform-row path was built and the same suites passed. The web's 19 isolated image-kernel comparisons (4 synthetic +15 licensed SmartDoc frames) introduced no clipped/brightened channels or changed RGB channel differences relative to the old curve on that set. Small synthetic gradient gains are not OCR accuracy or a guarantee of quality on unseen documents.

Paired timing on this Windows x64 desktop used baseline/new DLLs alternating in one process, six runs per size/version, median excluding the first, no other build/test running.
